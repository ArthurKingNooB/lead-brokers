# Proyecto para Portfolio Workana

## Titulo sugerido
Sitio web inmobiliario con panel administrativo, base de datos y consultas por WhatsApp

## Descripcion corta
Desarrolle una pagina web funcional para una empresa de intermediacion inmobiliaria y comercial. El sitio permite mostrar terrenos disponibles, abrir fichas completas, consultar por WhatsApp, agendar visitas y administrar propiedades desde un panel privado.

## Descripcion completa
Este proyecto fue creado para una empresa dedicada a la venta e intermediacion de terrenos, propiedades, locales y servicios para negocios. El objetivo fue construir una web profesional, clara y facil de usar, donde los clientes puedan ver oportunidades disponibles y contactar rapidamente por WhatsApp.

La pagina incluye una seccion de terrenos con tarjetas visuales, precio, ubicacion, superficie, estado de disponibilidad y acceso a una ficha ampliada. Cada ficha cuenta con galeria de imagenes, descripcion completa, datos del vendedor, mapa de Google Maps, boton para consultar y boton para agendar visita.

Tambien se desarrollo un panel privado para administracion, donde la persona encargada puede iniciar sesion, cargar nuevos terrenos, editar informacion, cambiar imagenes, eliminar fotos guardadas, marcar estados como Disponible, Reservado o Vendido, y revisar clientes registrados.

El proyecto cuenta con conexion a base de datos mediante Supabase y despliegue en Vercel, permitiendo que los cambios realizados desde el panel se vean en todos los dispositivos.

## Funcionalidades destacadas
- Diseno responsive para celulares, tablets y escritorio.
- Catalogo de terrenos disponibles.
- Fichas individuales para cada terreno.
- Galeria de imagenes con zoom, miniaturas, contador y flechas.
- Botones de WhatsApp con mensajes automaticos personalizados.
- Boton para agendar visita.
- Integracion con Google Maps.
- Panel administrativo privado.
- Carga, edicion y eliminacion de terrenos.
- Carga multiple de imagenes desde PC.
- Compresion de imagenes antes de guardarlas.
- Estados de terreno: Disponible, Reservado y Vendido.
- Registro de clientes interesados.
- Panel de estadisticas.
- Base de datos en Supabase.
- Deploy gratuito en Vercel.
- Dominio preparado para conexion personalizada.
